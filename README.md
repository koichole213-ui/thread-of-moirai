# 摩伊之线

SillyTavern 大纲规划与剧情引导插件，当前版本 **0.1.1-preview.3**。通过主面板与贴边悬浮窗规划故事、手动管理阶段，为下一轮回复选择方向。

## 已实现

- 根据当前人物、User 人设、所选世界书、创作预设及聊天范围生成大纲；先预览，再采用。
- 手动新增、修改、删除、排序阶段，重写当前阶段、按实际聊天调整后续。阶段不会自动推进。
- 每次生成 4–5 个方向，可按顺序选一到两个；主面板和悬浮窗同步。
- 放进酒馆输入框或发送时附带；重复插入只替换本插件准确记住的段落，用户改过的内容保留并提示核对。
- 按聊天保存大纲、阶段、偏好、模式及引导快照；正常成功回复清空本轮选择与偏好，失败/取消保留。重生成支持原轮引导与明确修改后的引导，当前回复版本保留自身快照。
- 世界书可从酒馆全部目录中选择，每页 12 本、条目分批显示；角色变化时更新跟随组、保留额外手选，记住条目选择。同一角色下主动取消的书不会在生成时偷偷加回。
- 主 API / 独立 API、共享 API 配置预设、可选副 API。副 API 只用于换一批和修改候选，其他任务继续使用主配置。
- 专用摘要、待办、小剧场预设条目默认排除，可逐条恢复；混合条目不自动改写。原酒馆资料和创作预设不被修改。

## 安装与使用

本分支是设置 UI 测试版，分支名为 `codex/settings-ui-preview`；直接使用默认分支会安装稳定版。

首次安装时，在酒馆「扩展 → 安装扩展」中填入仓库地址，并在「分支或标签名」中填写 `codex/settings-ui-preview`，然后刷新页面：

```text
https://github.com/koichole213-ui/thread-of-moirai
```

已经安装时，在扩展管理里找到「摩伊之线」，使用「切换分支」选择 `codex/settings-ui-preview`，刷新页面。设置页底部应显示 **0.1.1-preview.3**；需要回到稳定版时切回 `main`。上述入口适用于支持扩展分支管理的酒馆版本。

右边的「阶段 / 选项」窄按键可分别打开悬浮页；点击另一个入口切页，点击当前入口收起。阶段页可以查看完整大纲；主面板采用全屏布局，在「大纲」页选择参考资料与模型、填写故事偏好，再生成大纲。也可在魔法棒菜单点击「摩伊之线」，或展开酒馆扩展设置里的「摩伊之线 · 剧情推进」，点击「打开摩伊之线」。

扩展设置中可开关悬浮入口和闲置贴边收纳，也可重置位置。拖动时悬浮条沿上下左右跟随，松手后吸附到左/右侧并记住位置；收纳后点击窄条恢复。把手支持方向键调整位置。隐藏入口不关闭剧情引导，仍可从魔法棒打开；入口偏好与聊天、模型设置分别保存。

生成结果先预览再采用；阶段由你手动切换。选好方向后，可放入输入框或在发送时附带，插件不会自动发送消息。

## 当前兼容与保存边界

- 主 API 当前接入酒馆的**聊天补全**连接，接口依据本机 SillyTavern 1.18.0 源码核对。其他主 API 类型会明确提示使用独立 API，不会静默改用别的模型。
- 独立 API 支持 OpenAI 兼容、Anthropic 和自动识别，浏览器直接连接服务；服务需要允许浏览器跨域请求。主、副连接的地址、模型、请求格式与 Key **自动保存到酒馆插件设置，刷新后保留**。密钥与聊天数据分开保存，界面只显示是否已保存；点「清除密钥」清除当前连接的关联，其他已保存预设独立保留。API 预设按钮直接保存连接，参考资料仍用底部保存按钮。
- 主、副 API 均支持主动拉取模型列表和下拉选择；不支持列表的接口仍可手动填写。拉取列表只发目录请求，不生成文本；关闭设置、修改地址或切换预设会取消旧目录请求。
- 剧情数据使用酒馆聊天元数据保存。写入后回读同一聊天的本插件保存标识，以识别宿主吞掉保存错误的情况；不直接覆盖整份聊天。失败草稿保留在当前页面，遇到失败提示应重试后再刷新。
- 角色资料和世界书条目只在本地页面构造请求。所选世界书按界面范围直接读取，不模拟酒馆聊天的关键词触发扫描。
- 大纲“逐阶段揭晓”隐藏未来标题与内容；候选请求只包含当前阶段。规划新故事默认不读旧聊天，但可手动开启，不会清空原聊天。
- 预设过滤针对专用任务名称，无法保证识别所有私人预设的混合规则。返回内容必须通过阶段/候选结构校验，失败不会替换原数据。
- 复制聊天会随酒馆元数据继承一份大纲，后续进度独立。删除/回退只提示核对阶段，不替用户决定新阶段。

## 验证与开发

无需安装 npm 依赖。执行 `npm test` 运行核心合成测试；`npm run check` 检查语法和新增文件空白。受限 Windows 环境若不允许 Node 嵌套创建进程，可直接对源码执行 `node --check`，再运行 `node scripts/check.mjs --whitespace-only`。

`tests/harness.html` 使用正式入口和 UI，替换酒馆环境与模型返回，所有资料均为合成内容。用本地静态服务器打开 `tests/harness.html?test=1` 会执行浏览器回归，只清理它自己的测试存储。它不加载或修改真实聊天，不产生创作 API 消耗。

正式界面资源在 `ui/`，交互代码在 `src/ui.js`、`src/settings-ui.js`、`src/tabs.js` 中维护。运行 `python scripts/package.py` 生成 `dist/thread-of-moirai-0.1.1-preview.3.zip`，仅包含安装所需文件。内部 `st-plot` 存储标识保持稳定，以兼容已保存的数据。

首版已通过核心合成测试与隔离浏览器检查。实际酒馆主题/其他插件并发、群聊、真实模型写作效果、手机触控与软键盘仍需真实环境验收，不能用合成测试代替。

请求兼容模块来源及 MIT 许可见 `vendor/st-theater/README.md` 和 `LICENSE.txt`。
